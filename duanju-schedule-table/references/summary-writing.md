# 拍摄内容写作与验收

本规则适用于所有能阅读剧本的制表AI，不绑定某个平台、剧名或人物名单。以下为虚构教学片段，不是任何用户剧本的实际剧情；只能学习概括方法，不能照搬事件。

## 从正文到一句概括

1. 先读完整场，再按已经复核的转场边界读本行对应片段；其他片段仅帮助理解身份与衔接，不能把它们的事件填入本行。
2. 找出主要人物，以及本段最重要的动作、谈话主题、冲突、透露的信息或实际变化。不是所有片段都有发现、反转或结果；有就保留，没有就不补。
3. 用“谁＋核心动作/谈话内容＋必要的回应/结果”写一句自然短句。完整人物关系、对话主题和否定词不能为了卡18字删掉；简单动作不为凑12字添加地点、时间或情绪。
4. 对照正文检查每项事实的出处。角色陈述未必是事实，推测未必被证实；不要强化为“揭穿、证实、偷走、杀害”等正文没有确定的结论。
5. 读者只看这句，应能知道本段主要拍什么。若换一批人名仍能套用到任意对白戏，如“二人低声交谈”，就必须回正文补具体内容。

## 有正文依据的对照例子

| 本段原文示例 | 不合格写法 | 可用概括 | 判断依据 |
| --- | --- | --- | --- |
| 老周对林晓说：“昨夜我看见李管事把账本拿走了。” | 医院日内老周向林晓陈述 | 老周称昨夜看见李管事拿走账本 | 保留说法归属，写明陈述内容；不改成李管事偷账本 |
| 林晓问门卫：“昨夜是谁来取信？”门卫：“李管事。” | 林晓与门卫低声对话 | 林晓询问取信人得知是李管事 | 问题与回答都在本段，允许概括得到的信息 |
| 林晓问门卫谁拿走信件，门卫摇头说不知道。 | 林晓查明信件被李管事取走 | 林晓追问信件去向门卫称不知 | 不能编答案、丢掉否定或把“称不知”写成确实不知 |
| 林晓整理采访笔记，发现两名证人的时间说法不同。 | 林晓在报社整理采访笔记 | 林晓核对采访笔记发现证词时间矛盾 | 本段重点是发现时间矛盾，不只是整理动作 |
| 林晓拿出弟弟旧信，逐封翻看，随后收回抽屉。 | 林晓翻信发现弟弟失踪的线索 | 林晓翻看弟弟旧信后收好 | 正文只有翻看与收存，不补“发现线索” |
| 林晓靠墙等候。弟弟独自走进诊室，门关上。 | 林晓焦急等待弟弟抢救结果 | 林晓靠墙等候弟弟就诊 | 未写抢救或焦急，不能自行加重情节 |
| 两人坐着没有说话，林晓伸手握住顾川的手。 | 林晓握手安慰顾川放弃报复 | 林晓沉默中握住顾川的手 | 握手可以是本段主要动作；不猜动机或后续决定 |
| 原文仅写“林晓与老周低声交谈”，未提供具体对白或主题。 | 林晓与老周商定藏匿账本 | 林晓与老周低声交谈内容未交代 | 备注原文未提供具体对白、谈话内容需确认；不能为通过检查编主题，也不能擅称声音不可闻 |
| 雨夜街道空镜，店铺依次熄灯。 | 两人冒雨赶往商铺寻找失物 | 雨夜街道店铺依次熄灯 | 空镜直接概括画面主体与变化，无需人物或额外剧情 |

以上可用概括也必须与实际正文一致才能采用。不能仅因句式相似就填入相同结论。

## 重复场号仍分别写内容

假设同一原场分为三段：

| 显示场号 | 本段正文依据 | 本行拍摄内容 |
| --- | --- | --- |
| 1-1 客厅 | 林晓发现信封封口被拆开，起身去找门卫。 | 林晓发现信封被拆开后起身寻人 |
| 1-1a 院子 | 林晓问谁送来信；门卫说是一个陌生男子。 | 林晓询问送信人门卫称是陌生男子 |
| 1-1 客厅 | 林晓回来翻看信封，核对上面的邮戳。 | 林晓返回核对信封上的邮戳 |

三段各自保留自己的事件，不把第二段的回答写进第一段，也不能在第三段加上正文没有的“识破来信人”。分场表只调整行序，不重新生成摘要。

## 检查程序的边界

- 草稿未提供经复核的 `summary` 时，统一显示“待复核：需通读本段正文概括”。正式构建拒绝这一占位，不再生成看似完整的18字截句。
- 正式检查拒绝非文本/空内容、待复核占位，以及在已知人物与地点范围内识别到的“某人与某人交谈”等明显空泛模板；可识别的“地点＋日内/夜外＋人物”表头拼接也要求修改。
- 不是禁用“陈述、谈、问”等动词：有具体内容的“林晓向老周陈述昨夜经过”“林晓就取信经过向老周陈述”都可以。也不会把“靠墙等待、翻旧信、握手”等动作一律判错。
- 自动检查范围有限，不能核实所有事实、动机、说法归属、主次或遗漏。即使检查通过，也必须逐段对照正文完成上述语义验收；不要求用户代替制表AI做常规复核。
- 旧配置里的摘要需要按此规则逐行检查；不能只替换“交谈”等关键词、补上“事件真相/重要线索”来绕过检查。
